    Pendências para a próxima atualização

      Transações

      Competência: compras de cartão contam no mês em que foram feitas (mês anterior ao pagamento da fatura); no regime de pagamento, tudo conta no dia em que saiu ou entrou na conta. Giros entre contas próprias aparecem marcados e ficam fora dos totais.

      Documentos guardados

      Extratos importados e itens de fatura processados são arquivados aqui automaticamente, criptografados junto com os dados. Para enviar um novo extrato ou fatura, use a aba Configurações.
      Importar para os lançamentos
      Só anexar e enviar — a ferramenta reconhece sozinha se é extrato (Sicredi ou Nubank) ou fatura de cartão, e no caso da fatura identifica também o cartão e o mês (dá para corrigir na revisão, se precisar). Extrato: ignora o que já está conciliado, classifica pelas regras do teu pipeline e nada entra sem a conciliação no centavo fechar. Fatura: pode ser enviada a qualquer momento, mesmo antes de fechar — fica guardada criptografada, já classificada, e entra no caixa no dia do pagamento, quando o débito aparecer na importação do extrato.
      Projeção 2027 — premissas
      Valem para a visão "2027 — projeção" no Fluxo. Ficam guardadas criptografadas no cofre e sincronizadas entre os aparelhos.
      Metas — alvos
      O progresso das metas aparece na aba Patrimônio.
      Patrimônio por print ✨
      Anexe a captura de tela da posição (Sicredi, Nubank, corretora…). A IA lê os nomes e valores, e você confere item por item: atualizar uma reserva existente, criar uma nova (com o prazo de resgate) ou ignorar — nada é gravado sem a sua confirmação. Precisa da classificação com IA ativa; o print não fica guardado, só os valores confirmados, criptografados no cofre como tudo aqui.
      Usuários com acesso
      Como administrador, você cria e exclui usuários. Cada pessoa entra com o próprio usuário e senha — a senha nunca fica gravada em lugar nenhum, ela é a chave que abre os dados.

      Publicação automática na base
      Com isso ativo, toda alteração (acessos, importações, documentos) vai sozinha para a base — em ~1 minuto vale em todos os aparelhos. Como gerar a chave (2 min): github.com → foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access: Only select repositories → painel-estacao-operacional → Permissions → Contents: Read and write → Generate → cole aqui. A chave fica guardada criptografada dentro do cofre, nunca em texto aberto.
      Classificação inteligente (IA)
      Com isso ativo, o site chama o Claude (a mesma IA daqui do Cowork) ao ler extratos e faturas: o que as regras fixas não reconhecem é classificado pela IA seguindo a tua metodologia, marcado com ✨ para conferência — e dá até para ler faturas coladas em formato bagunçado (texto de PDF, por exemplo). Como obter a chave (2 min): console.anthropic.com → API Keys → Create Key → cole aqui. Ela fica guardada criptografada no cofre. Apenas descrições e valores dos lançamentos são enviados para classificar; custo típico: centavos por fatura.
